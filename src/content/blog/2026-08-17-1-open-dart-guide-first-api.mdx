## 생각보다 제공하는 정보가 엄청 많다

처음에는 DART에서 올라오는 공시 목록 정도를 API로 가져올 수 있을 거라고 생각했다.

그런데 개발가이드를 보니 크게 다음과 같이 나뉘어 있었다.

* 공시정보
* 정기보고서 주요정보
* 정기보고서 재무정보
* 지분공시 종합정보
* 주요사항보고서 주요정보
* 증권신고서 주요정보

각 항목 안에는 또 여러 개의 API가 있다.

공시검색, 기업개황, 재무제표, 배당, 지분변동 같은 정보뿐 아니라 유상증자, 무상증자, 영업정지, 소송, 합병, 전환사채 같은 항목도 별도의 API로 제공하고 있었다.

솔직히 지금은 대부분이 무슨 의미인지 잘 모른다.

주식에 대해 아는 것이 거의 없는 상태에서 이걸 전부 이해하려고 하면 시작도 못 할 것 같다.

일단 AlphaSkan에 당장 필요할 것 같은 것만 생각해보기로 했다.

## AlphaSkan에는 어떤 API가 먼저 필요할까?

지금 AlphaSkan에서 가장 먼저 하고 싶은 것은 **새로운 공시가 올라왔는지 감지하는 것**이다.

그래서 가장 먼저 눈에 들어온 것은 `공시검색` API다.

공시검색을 이용하면 날짜나 회사 등의 조건으로 공시 목록을 가져올 수 있는 것 같다.

그 다음으로는 이런 것들이 필요할 것 같다.

### 공시검색

새로운 공시가 올라왔는지 찾기 위한 가장 기본적인 API.

아마 AlphaSkan이 계속 확인하게 될 핵심 데이터가 될 것 같다.

### 고유번호

DART에서는 기업마다 별도의 고유번호를 사용하는 것 같다.

나중에 DART의 회사와 실제 주식 종목코드를 연결하려면 필요할 것 같다.

### 기업개황

회사명, 종목코드 등 기업의 기본정보를 확인할 때 사용할 수 있을 것 같다.

### 주요사항보고서 주요정보

여기가 특히 재미있어 보였다.

목록을 보니 이런 정보들이 있었다.

* 부도발생
* 영업정지
* 유상증자 결정
* 무상증자 결정
* 감자 결정
* 소송 등의 제기
* 전환사채권 발행결정

아직 각각의 이벤트가 주가에 어떤 영향을 주는지는 전혀 모르겠다.

그래도 AlphaSkan에서 나중에 **기업 이벤트를 자동으로 찾아내고 시장의 반응을 기록하려면 이런 데이터가 중요하지 않을까** 하는 생각이 들었다.

당장은 욕심내지 않고 `공시검색` 하나부터 시작하기로 했다.

## 공시검색 API를 처음 호출해봤다

개발가이드의 공시검색 페이지에 들어가보니 요청 URL과 파라미터들이 설명되어 있었다.

API 주소는 다음과 같다.

```text
https://opendart.fss.or.kr/api/list.json
```

여기에 발급받은 API Key와 조회 날짜 등을 붙여서 요청하면 된다.

예를 들면 이런 형태다.

```text
https://opendart.fss.or.kr/api/list.json
?crtfc_key=API_KEY
&bgn_de=20260817
&end_de=20260817
&corp_cls=Y
&page_no=1
&page_count=10
```

API Key는 공개되면 안 되기 때문에 실제 값 대신 `API_KEY`라고 적어두었다.

curl로도 호출해봤다.

```bash
curl "https://opendart.fss.or.kr/api/list.json?crtfc_key=API_KEY&bgn_de=20200117&end_de=20200117&corp_cls=Y&page_no=1&page_count=10"

```

그리고 정말 JSON이 내려왔다.

```json
{
  "status": "000",
  "message": "정상",
  "page_no": 1,
  "page_count": 10,
  "total_count": 210,
  "total_page": 2,
  "list": [
    {
      "corp_code": "00120182",
      "corp_name": "NH투자증권",
      "stock_code": "005940",
      "corp_cls": "Y",
      "report_nm": "[첨부추가]일괄신고추가서류(파생결합증권-주가연계증권)",
      "rcept_no": "20200117000559",
      "flr_nm": "NH투자증권",
      "rcept_dt": "20200117",
      "rm": ""
    },
    {
      "corp_code": "00120182",
      "corp_name": "NH투자증권",
      "stock_code": "005940",
      "corp_cls": "Y",
      "report_nm": "[첨부추가]일괄신고추가서류(파생결합증권-주가연계증권)",
      "rcept_no": "20200117000486",
      "flr_nm": "NH투자증권",
      "rcept_dt": "20200117",
      "rm": ""
    }
  ]
}

```

개발자로서는 그냥 평범한 REST API 응답인데, 주식 관련 데이터를 직접 받아본 것은 처음이라 조금 신기했다.

필드 이름을 보니 대략 짐작은 된다.

* `corp_name` : 회사명인 것 같다.
* `report_nm` : 공시 제목인 것 같다.
* `rcept_no` : 접수번호?
* `rcept_dt` : 접수일자일 것 같다.

각 필드가 정확히 무엇을 의미하는지는 다음에 하나씩 알아보면 될 것 같다.

## 일단 첫 번째 데이터는 가져왔다

아직 AlphaSkan 프로그램은 시작도 하지 않았다.

오늘 한 일은 OpenDART 개발가이드에 어떤 API들이 있는지 둘러보고, 그중에서 AlphaSkan에 먼저 필요할 것 같은 API를 생각해본 뒤 `공시검색` API를 한 번 호출해본 것이 전부다.

그래도 처음으로 AlphaSkan에서 사용할 실제 데이터를 가져와봤다.

지금은 브라우저나 curl로 직접 요청했지만, 다음에는 **Node.js에서 이 API를 호출해서 오늘 올라온 공시를 출력해보려고 한다.**

그때부터 조금씩 프로그램다운 모습이 시작되지 않을까 싶다.
