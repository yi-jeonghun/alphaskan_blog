지난번에는 OpenDART의 `공시검색` API를 브라우저와 curl로 직접 호출해봤다.

API Key와 날짜를 넣어 요청하니 실제 공시 데이터가 JSON으로 내려왔다.

이번에는 여기서 한 단계 더 나아가 보기로 했다.

**AlphaSkan 프로그램 안에서 직접 OpenDART API를 호출해보는 것.**

아직 데이터베이스도 없고, 웹 화면도 없고, 주가 데이터도 없다.

이번 목표는 아주 단순하다.

> **Node.js 코드에서 OpenDART API를 호출하고 공시 목록을 콘솔에 출력해본다.**

## 어떤 언어로 만들까?

주식이나 데이터 분석 관련 프로그램을 찾아보면 Python을 사용하는 경우가 굉장히 많은 것 같다.

아마 데이터 분석이나 머신러닝 분야에서 Python이 많이 사용되는 이유가 있을 것이다.

하지만 나는 웹 개발이 가장 익숙하고 Node.js와 TypeScript를 편하게 사용할 수 있다.

AlphaSkan도 나중에는 서버에서 데이터를 수집하고 웹이나 PWA를 통해 확인하는 형태로 만들 생각이다.

그래서 처음부터 익숙하지 않은 기술을 선택하기보다는 **Node.js + TypeScript**로 시작하기로 했다.

나중에 통계 분석이나 머신러닝 때문에 Python이 필요해지면 그때 추가하면 될 것 같다.

## AlphaSkan 프로젝트를 만든다

블로그 프로젝트와 실제 AlphaSkan 프로그램은 별도의 Repository로 관리하기로 했다.

처음부터 복잡한 구조를 만들 필요는 없을 것 같아서 아주 단순하게 시작했다.

```text
alphaskan/
├── src/
│   └── index.ts
├── .env
├── .env.example
├── .gitignore
├── package.json
└── tsconfig.json
````



지금 단계에서는 `src/index.ts` 하나면 충분하다.

API를 호출하고 결과를 콘솔에 출력하는 것이 전부이기 때문이다.


## 프로잭트 초기화

```bash
npm init
```



## 필요한 패키지 설치

프로젝트를 받은 뒤 필요한 Node.js 패키지를 설치한다.

```bash
npm install dotenv
```
```bash
npm install -D typescript tsx @types/node
```



이번 프로젝트에서는 TypeScript를 실행하기 위한 최소한의 패키지만 사용했다.

현재 Node.js에는 `fetch`가 기본으로 제공되기 때문에 HTTP 요청을 위해 axios 같은 라이브러리를 따로 추가하지 않았다.

## API Key는 코드에 넣지 않는다

OpenDART API를 호출하려면 지난번에 발급받은 API Key가 필요하다.

하지만 다음처럼 코드에 직접 넣으면 안 된다.

```ts
const apiKey = "실제_API_KEY";
```

GitHub에 소스코드를 올리면 API Key도 함께 공개될 수 있기 때문이다.

그래서 API Key는 `.env` 파일에 저장했다.

```text
OPENDART_API_KEY=발급받은_API_KEY
```

그리고 `.env` 파일은 GitHub에 올라가지 않도록 `.gitignore`에 추가한다.

```text
node_modules/
.env
```

대신 어떤 환경변수가 필요한지는 알 수 있도록 `.env.example` 파일에는 이름만 남겨두었다.

```text
OPENDART_API_KEY=
```

웹 개발을 하면서 평소에도 자주 사용하는 방식인데, 이렇게 하나씩 기록하면서 만들다 보니 왜 이런 작업을 하는지도 다시 생각하게 된다.

## OpenDART 공시검색 API 호출

지난번 curl로 호출했던 API는 다음 주소였다.

```text
https://opendart.fss.or.kr/api/list.json
```

이번에는 같은 요청을 Node.js 코드에서 보낸다.

대략적인 흐름은 단순하다.

```text
오늘 날짜 구하기
       ↓
OpenDART API 호출
       ↓
JSON 응답 받기
       ↓
공시 목록 출력
```

조회 날짜는 직접 `20260817`처럼 적지 않고 프로그램이 실행되는 날짜를 기준으로 만들었다.

한국 주식시장 데이터를 다루는 프로그램이므로 날짜도 한국 시간 기준으로 처리하도록 했다.

API 요청에는 다음 정보가 들어간다.

```text
API Key
조회 시작일
조회 종료일
페이지 번호
가져올 공시 개수
```

이번에는 오늘 올라온 공시 중 최대 10건만 가져오도록 했다.

> index.ts 파일
```typescript
import "dotenv/config";

interface DartDisclosure {
	corp_cls: string;
	corp_name: string;
	corp_code: string;
	stock_code: string;
	report_nm: string;
	rcept_no: string;
	flr_nm: string;
	rcept_dt: string;
	rm: string;
}

interface DartResponse {
	status: string;
	message: string;
	page_no?: number;
	page_count?: number;
	total_count?: number;
	total_page?: number;
	list?: DartDisclosure[];
}

function getTodayInSeoul(): string {
	const parts = new Intl.DateTimeFormat("en-US", {
		timeZone: "Asia/Seoul",
		year: "numeric",
		month: "2-digit",
		day: "2-digit",
	}).formatToParts(new Date());

	const year = parts.find((part) => part.type === "year")?.value;
	const month = parts.find((part) => part.type === "month")?.value;
	const day = parts.find((part) => part.type === "day")?.value;

	if (!year || !month || !day) {
		throw new Error("오늘 날짜를 계산하지 못했습니다.");
	}

	return `${year}${month}${day}`;
}

function formatDate(date: string): string {
	if (date.length !== 8) {
		return date;
	}

	return `${date.slice(0, 4)}-${date.slice(4, 6)}-${date.slice(6, 8)}`;
}

async function fetchDisclosures(
	apiKey: string,
	date: string,
): Promise<DartResponse> {
	const params = new URLSearchParams({
		crtfc_key: apiKey,
		bgn_de: date,
		end_de: date,
		corp_cls:'Y',
		page_no: "1",
		page_count: "10",
	});

	const response = await fetch(
		`https://opendart.fss.or.kr/api/list.json?${params.toString()}`,
	);

	if (!response.ok) {
		throw new Error(
			`OpenDART HTTP 오류: ${response.status} ${response.statusText}`,
		);
	}

	return (await response.json()) as DartResponse;
}

async function main() {
	const apiKey = process.env.OPENDART_API_KEY;

	if (!apiKey) {
		console.error("OPENDART_API_KEY가 설정되지 않았습니다.");
		console.error(".env 파일에 OpenDART API Key를 설정해주세요.");
		process.exitCode = 1;
		return;
	}

	let today = getTodayInSeoul();
	today = "20260814";

	console.log("OpenDART 공시 조회");
	console.log(`조회일: ${formatDate(today)}`);
	console.log("");

	try {
		const result = await fetchDisclosures(apiKey, today);

		// OpenDART에서 조회 결과가 없을 때
		if (result.status === "013") {
			console.log("오늘 조회된 공시가 없습니다.");
			return;
		}

		// 정상 응답이 아닐 때
		if (result.status !== "000") {
			console.error("OpenDART API 오류");
			console.error(`status: ${result.status}`);
			console.error(`message: ${result.message}`);
			process.exitCode = 1;
			return;
		}

		const disclosures = result.list ?? [];

		console.log(`공시 수: ${disclosures.length}`);
		console.log("");

		if (disclosures.length === 0) {
			console.log("오늘 조회된 공시가 없습니다.");
			return;
		}

		disclosures.forEach((disclosure, index) => {
			console.log(`${index + 1}. ${disclosure.corp_name}`);

			if (disclosure.stock_code) {
				console.log(`   종목코드: ${disclosure.stock_code}`);
			}

			console.log(`   공시: ${disclosure.report_nm}`);
			console.log(`   접수일: ${disclosure.rcept_dt}`);
			console.log("");
		});
	} catch (error) {
		console.error("공시 조회 중 오류가 발생했습니다.");

		if (error instanceof Error) {
			console.error(error.message);
		} else {
			console.error(error);
		}

		process.exitCode = 1;
	}
}

main();
```




## 실행해본다

프로그램 실행 명령은 다음과 같다.

```bash
npm run dev
```

현재 `npm run dev`는 웹 서버를 실행하는 것이 아니다.

`src/index.ts`를 실행해서 OpenDART API를 호출하고 결과를 터미널에 출력한다.

실행해보니 실제 공시 데이터가 내려왔다.

curl에서 JSON이 내려오는 것을 이미 확인했기 때문에 기술적으로는 크게 새로운 일은 아니다.

그래도 느낌은 조금 달랐다.

이제는 브라우저나 터미널에서 API를 직접 호출하는 것이 아니라 **내가 만들기 시작한 AlphaSkan 프로그램이 실제 DART 데이터를 가져오고 있다.**

아직 정말 작은 코드지만 AlphaSkan의 첫 번째 동작이라고 할 수 있을 것 같다.
